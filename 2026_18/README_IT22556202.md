# IT22556202 Contribution

## Backend Data Processing and MongoDB Storage

### Responsibilities

Implementing the backend system that receives sensor data from the MQTT broker and stores the data in a MongoDB database for analysis and visualization.

### Implemented Components

* MQTT subscriber using Python
* JSON message processing
* MongoDB database integration
* Data storage with timestamp

### Code Files

* iotbda\_backend

### Technologies Used

* Python
* Paho MQTT Client
* MongoDB
* PyMongo

### Database Configuration

Database Name:
iotbda\_database

Collection Name:
sensor\_readings

### Key Technical Tasks

* Subscribed to MQTT topic to receive sensor data
* Decoded incoming JSON messages
* Parsed sensor data fields
* Inserted sensor data into MongoDB database
* Added timestamps for each sensor record

{
"temperature": 29.4,

### Outcome

The backend system successfully receives real-time sensor data from the MQTT broker and stores it in MongoDB, enabling future data analysis, visualization, and machine learning applications.
