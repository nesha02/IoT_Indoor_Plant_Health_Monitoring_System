# IT22850232 Contribution
## Environmental Sensor Integration (DHT22 & BH1750)

### Responsibilities
Integrating the environmental sensors used in the IoT plant monitoring system. The sensors include the DHT22 temperature and humidity sensor and the BH1750 light intensity sensor.

### Implemented Components
- DHT22 sensor integration
- BH1750 light intensity sensor integration
- Sensor wiring and pin configuration
- Sensor testing using serial monitor

### Code Files
- DHT22_sensor_temperature_humidity_codes
- BH1750_sensor_light_intensity

### Hardware Configuration

DHT22 Sensor
- DATA → GPIO19
- VCC → 3.3V
- GND → GND

BH1750 Light Sensor
- SDA → GPIO21
- SCL → GPIO22
- VCC → 3.3V
- GND → GND

### Key Technical Tasks
- Implemented digital communication with DHT22
- Implemented I2C communication with BH1750
- Verified sensor readings through serial monitoring
- Handled sensor read failures using basic validation

### Outcome
Both environmental sensors successfully read real-world data including temperature, humidity, and ambient light levels, which are transmitted to the ESP32 processing unit.
