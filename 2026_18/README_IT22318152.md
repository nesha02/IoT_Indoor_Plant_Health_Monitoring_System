# IT22318152 Contribution

## ESP32 Sensor Integration and MQTT Data Publishing

### Responsibilities

Integrating all sensors with the ESP32 microcontroller and implementing the MQTT-based data transmission system used to send sensor data to the backend system.

### Implemented Components

* Integration of all sensors into a single ESP32 program
* Sensor data aggregation
* JSON data formatting
* MQTT communication implementation
* WiFi connectivity configuration

### Code Files

* all\_sensor\_readings
* esp32\_iotbda\_sensor\_mqtt\_json

### Network Configuration

MQTT Broker:
broker.hivemq.com

MQTT Topic:
iotbda/sensors

### Key Technical Tasks

* Read sensor data from DHT22, BH1750, and soil moisture sensors
* Combined sensor readings into a single ESP32 application
* Structured sensor data into JSON format
* Implemented MQTT publishing using PubSubClient library
* Implemented WiFi connection and MQTT reconnection handling

### Example JSON Payload

{
"temperature": 29.4,
"humidity": 64.1,
"soil1": 1870,
"soil2": 2050,
"soil3": 1725,
"light": 342.6
}

### Outcome

The ESP32 successfully collects sensor data, formats the data into JSON structure, and publishes the readings through MQTT to the cloud communication layer.
