# IT22335364 Contribution

## Soil Moisture Sensor Integration

### Responsibilities

Integrating the soil moisture sensing components of the IoT plant monitoring system. Three soil moisture sensors were used to monitor the moisture levels of multiple plants.

### Implemented Components

* Soil moisture sensor 1 integration
* Soil moisture sensor 2 integration
* Soil moisture sensor 3 integration
* Analog sensor wiring and configuration
* Sensor testing using serial monitor

### Code Files

* soil\_sensor\_01\_readings
* soil\_sensor\_02\_readings
* soil\_sensor\_03\_readings

### Hardware Configuration

Soil Moisture Sensor 1

* Signal → GPIO35
* VCC → 3.3V
* GND → GND

Soil Moisture Sensor 2

* Signal → GPIO34
* VCC → 3.3V
* GND → GND

Soil Moisture Sensor 3

* Signal → GPIO32
* VCC → 3.3V
* GND → GND

### Key Technical Tasks

* Configured ESP32 ADC pins to read analog sensor values
* Implemented soil moisture data acquisition using analogRead()
* Verified sensor readings through serial monitoring
* Ensured sensor readings remain within ESP32 ADC range (0–4095)

### Outcome

All three soil moisture sensors successfully collect raw soil moisture values from the plant pots and transmit the readings to the ESP32 for further processing.
